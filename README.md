# 🛒 Walmart Sales Analysis using MySQL & Power BI

## 📌 Project Overview

This project analyzes Walmart's weekly sales data using MySQL and Power BI. The objective is to uncover sales trends, evaluate store performance, analyze holiday impacts, and generate business insights to support data-driven decision-making.

---

## 🎯 Objectives

- Clean and preprocess Walmart sales data
- Perform SQL-based business analysis
- Solve 25 real-world business questions
- Build an interactive Power BI dashboard
- Generate actionable business insights

---

## 🛠️ Tools & Technologies

- MySQL
- Power BI
- Microsoft Excel
- GitHub

---

## 📂 Dataset Information

- Total Records: 6,435
- Stores: 45
- Time Period: 2010–2012

### Dataset Columns

- Store
- Weekly_Sales
- Holiday_Flag
- Temperature
- Fuel_Price
- CPI
- Unemployment
- Sales_Date

---

## 🧹 Data Preprocessing

- Imported dataset into MySQL
- Verified data types
- Converted date format
- Created Month and Year columns
- Checked for missing values
- Removed duplicate records
- Performed exploratory data analysis

## 💡 Key Business Insights

- Store 20 generated the highest total sales.
- The year 2011 recorded the highest overall sales.
- Non-Holiday weeks generated more total revenue than Holiday weeks.
- Sales showed clear seasonal fluctuations across the available period.
- Top-performing stores contributed significantly to total company revenue.
- Fuel price showed only a weak relationship with weekly sales.
- Temperature had minimal influence on overall sales performance.
- Store performance varied considerably across locations.
